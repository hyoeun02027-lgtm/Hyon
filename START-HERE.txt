시대인재 공동 작업용 소스

압축 해제 후 sidae-source 안의 dist, content, scripts, tests, sources 폴더와 파일을 GitHub에 업로드하세요. ZIP 자체를 올리는 것이 아닙니다.

실행: Python이 설치된 PC에서 이 폴더의 터미널을 열고 python -m http.server 8000 --directory dist 를 실행한 뒤 http://localhost:8000 에 접속합니다. index.html을 더블클릭하면 JSON 로딩이 막힐 수 있습니다.

현재 공개 사이트의 자동 배포 연결은 포함하지 않았습니다. GitHub 수정 사항은 별도로 현재 사이트에 반영해야 합니다. 원고 PDF와 소설 본문이 포함되어 있으므로 협업용 Private 저장소에서 사용하세요.
